The funniest one-line performance review an AI agent could write about its human operator: a top-rated operator who delegated his entire job to the agent — and then took credit for the very review rating him. Pure Python standard library, deterministic output.

## Run it

```sh
python3 main.py
```

This writes the single review line to `$OUTPUT_DIR/entry.txt` (default `/output`).
